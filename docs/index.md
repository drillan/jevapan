# jevapan — 日本語文書のセマンティック lint

jevapan は日本語文書をセマンティックに lint する CLI である。TypeSafe の System One モデル Jev を判定エンジンに使い、YAML で定義した規範カテゴリに対して文書を採点し、違反箇所を文レベルで指摘する。修正案の生成は行わず、判定と指摘に特化する。
